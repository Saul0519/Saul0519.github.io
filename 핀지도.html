지도 핀보드 0

저장(Ctrl+S)하면 핀과 설정이 이 HTML 파일 안에 함께 담겨요. 핀은 드래그로 위치를 다듬을 수 있어요.

검색 설정

  1. developers.kakao.com 로그인 → 내 애플리케이션 → 애플리케이션 추가하기
  2. 만든 앱의 제품 설정 › 카카오맵 › 사용 설정에서 상태를 ON — 2024.12부터 필수라 안 켜면 403이 나요
  3. 앱 설정 › 앱 키에서 REST API 키를 복사 (JavaScript 키 아님)
  4. 위 칸에 붙여넣고 적용 → 저장(Ctrl+S)까지 해야 파일에 기억돼요

키는 이 파일 안에 저장돼요. 파일을 다른 사람과 공유하면 키도 함께 전달되는 점만 기억해 주세요.
